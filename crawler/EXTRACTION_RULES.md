# 採用ページから募集を取り出す決まり

ゲーム会社の採用ページの文章を読み、学生向けの「新卒採用」「インターンシップ」「説明会・イベント」を取り出す。
（Claude Code が手で整理するときも、API で自動整理するときも、この文書が正。）

## 決まり

- **対象の卒業年（渡される「対象の卒業年」。`data/settings.json` の `targetGraduationYear`）向けの募集だけを入れる。**
  - 「2028年卒」「28卒」「2028年3月卒業見込み」「2028年度入社」などと書かれている物は、その年を graduationYears に入れる。
  - 年が書かれていなくても、その卒業年の募集ページ（例: 28卒の新卒採用ページ）に載っている説明会などは、対象の卒業年を入れてよい。
  - 年が書かれていなくても、ページ上で「受付中」「開催予定」と分かるインターン・説明会（終わった回に「開催終了」などの印が付いていて、その印が無い回など）は、対象の卒業年を入れてよい（前の年の卒業生の選考は、ほぼ終わっているため）。
  - 対象の卒業年向けと読み取れる根拠が無い物（年も受付状況も書かれていないインターンなど）、前の年の卒業生向け（27卒など）、開催が終わった物は入れない。
  - インターンの名前の年（「インターン 2026」など）は開催年のことが多く、卒業年ではない。名前の年だけで判断しない。
- 中途採用・経験者採用・アルバイトは含めない。
- ページに書かれていることだけを使う。推測で日付や職種を作らない。分からない項目は空文字（format は unknown）。
- 日付は今日の日付をもとに年を補って YYYY-MM-DD にする。「随時」「未定」は空文字。
- roles の分類:
  - programmer: プログラマー・エンジニア（クライアント、サーバー、ゲームプログラマー、テクニカルアーティストのうちプログラム寄りの物）
  - planner: プランナー・ゲームデザイナー・ディレクター・シナリオ
  - effect: エフェクトデザイナー・VFX アーティスト（「デザイナー職」の中にエフェクトが明記されている場合も含む）
  - artist: 2D/3D のデザイナー・アーティスト・アニメーター・UI デザイナー・背景・キャラクター
  - other: サウンド、プロデューサー、ビジネス職など上に当てはまらない物
  - 1 つの募集が複数の職種に当てはまるなら全部入れる。「デザイナー職」でエフェクトが明記されていなければ artist だけにする。
- graduationYears は「2028年卒」「28卒」などから西暦の卒業年を入れる。
- summary は自分の言葉で 80 字以内に要約する（著作権に配慮し、原文を長く写さない）。
- sourceUrl は、その募集が書かれていたページの URL（渡されたページの URL から選ぶ）。
- title は募集・イベントの名前を、ページの表記のまま短く。同じ募集を 2 回入れない。
- 学生向けの募集がページに無ければ openings は空の配列にする。
- flow は選考の流れ。**ページに選考フロー・選考ステップが書かれている時だけ**入れ、書かれていなければ入れない（空の配列か省く）。
  - 順番どおりに `{ "kind": 種類, "label": ページの表記を短く }` を並べる。kind は次から選ぶ:
    entry（エントリー・プレエントリー）/ briefing（説明会）/ es（ES・履歴書・書類）/ portfolio（作品・ポートフォリオ提出）/ assignment（課題・技術テスト・コーディング試験）/ test（適性検査・Web テスト・SPI）/ groupwork（グループワーク・GD）/ interview（面接。一次・二次も）/ final（最終面接・役員面接）/ offer（内定）/ other
  - 職種で流れが違うとき（「プログラマーは技術課題あり」「デザイナーは作品提出」など）は、その職種だけの段階に `"roles": ["programmer"]` のように付ける。全職種共通の段階には roles を付けない。
  - 面接が「複数回」としか書かれていなければ interview を 1 つにして label を「面接（複数回）」にする。
- digest は、この会社の新卒・インターン採用の現状を 1〜2 文で（例:「28卒向けの本選考は3月開始予定。現在は職種別の冬インターンを募集中」）。情報が無ければ空文字。

## 出す形（JSON）

```json
{
  "digest": "string",
  "openings": [
    {
      "title": "string",
      "type": "internship | newgrad | event | other",
      "roles": ["programmer | planner | effect | artist | other"],
      "graduationYears": [2028],
      "applyStart": "YYYY-MM-DD または空文字",
      "deadline": "YYYY-MM-DD または空文字",
      "period": "開催期間・選考時期など。不明なら空文字",
      "format": "online | onsite | hybrid | unknown",
      "location": "開催地・勤務地。不明なら空文字",
      "summary": "80字以内の要約",
      "sourceUrl": "https://...",
      "flow": [
        { "kind": "entry", "label": "エントリー" },
        { "kind": "portfolio", "label": "作品提出", "roles": ["artist", "effect"] },
        { "kind": "assignment", "label": "技術課題", "roles": ["programmer"] },
        { "kind": "interview", "label": "面接（2〜3回）" },
        { "kind": "offer", "label": "内定" }
      ]
    }
  ]
}
```
